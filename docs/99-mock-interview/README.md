# Mock interview drill

Five docs. Read in order — each one is independently useful but they reinforce each other.

| Doc | When to read | Time |
|---|---|---|
| [`01-likely-questions.md`](01-likely-questions.md) | Days before — drill the ⭐⭐⭐ first | 60 min first pass, drill over multiple sessions |
| [`02-system-design-rounds.md`](02-system-design-rounds.md) | Day before — rehearse the 3 lead-ins | 30 min |
| [`03-curveballs.md`](03-curveballs.md) | Day before — internalize the patterns | 20 min |
| [`04-rusty-stack-cheatsheets.md`](04-rusty-stack-cheatsheets.md) | Day before — refresh the speakable framings | 20 min |
| [`05-day-of-checklist.md`](05-day-of-checklist.md) | Night before AND morning of | 5 min each |

## Drill plan (7 days before interview)

```
D-7  Read 01-likely-questions in full. Mark questions you can't answer cold.
D-6  Draft your own one-paragraph answer for each ⭐⭐⭐ question on your hit list.
D-5  Rest day. Don't open any of this.
D-4  Out-loud rehearsal: 10 random questions from sec H (behavioral). Time yourself.
D-3  Read 02-system-design-rounds, draw whiteboard from memory on paper.
D-2  Read 03-curveballs and 04-rusty-stack-cheatsheets.
D-1  Read 05-day-of-checklist. Re-read your pitch. Set up your space. Sleep early.
D-0  Read 05-day-of-checklist morning of. Pitch one more time. Show up.
```

## The single most important thing in this folder

The "one-page summary" at the end of [`05-day-of-checklist.md`](05-day-of-checklist.md). If you read nothing else the morning of, read that.
